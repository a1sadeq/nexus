# Nexus v1.0.0 Release Packaging & Distribution Plan

> **For Antigravity:** REQUIRED SUB-SKILL: Load executing-plans to implement this plan task-by-task.

**Goal:** Package, verify, compute SHA-256 integrity checksums, and publish release v1.0.0 with binary assets (.AppImage, .deb, .pacman, and Windows .exe installer) to GitHub Releases.

**Architecture:** Verify local production builds for Linux and Windows, stage artifacts in `dist/`, calculate cryptographic checksums, create git release tag `v1.0.0`, and publish the release via GitHub API with binary attachments.

**Tech Stack:** Electron Builder, Node.js, GitHub REST API, Bash / SHA256.

---

### Task 1: Verify and Package Release Binaries

**Files:**
- Output directory: `dist/`
- Configuration: `electron-builder.yml`
- Package metadata: `package.json`

**Step 1: Check existing distribution binaries in `dist/`**

Run: `ls -lh dist/nexus*`
Expected: Presence of `nexus-1.0.0.AppImage`, `nexus_1.0.0_amd64.deb`, `nexus-1.0.0.pacman`, and `nexus-1.0.0-setup.exe`.

**Step 2: Generate SHA-256 Checksums Manifest**

Run: `cd dist && sha256sum nexus-1.0.0.AppImage nexus_1.0.0_amd64.deb nexus-1.0.0.pacman nexus-1.0.0-setup.exe > SHA256SUMS.txt && cat SHA256SUMS.txt`
Expected: 4 valid sha256 hashes generated in `dist/SHA256SUMS.txt`.

**Step 3: Verification of Checksums**

Run: `cd dist && sha256sum -c SHA256SUMS.txt`
Expected: All 4 files output `OK`.

---

### Task 2: Create and Push Git Tag `v1.0.0`

**Files:**
- Git repository: `.git`

**Step 1: Create annotated git tag**

Run: `git tag -a v1.0.0 -m "Nexus v1.0.0: Genesis Release"`
Expected: Tag `v1.0.0` created locally.

**Step 2: Push git tag to origin**

Run: `git push origin v1.0.0`
Expected: `[new tag] v1.0.0 -> v1.0.0` pushed to `https://github.com/a1sadeq/nexus.git`.

---

### Task 3: Publish GitHub Release and Upload Binary Assets

**Files:**
- API Client: `curl`
- Credentials: `~/.git-credentials`
- Assets:
  - `dist/nexus-1.0.0.AppImage`
  - `dist/nexus_1.0.0_amd64.deb`
  - `dist/nexus-1.0.0.pacman`
  - `dist/nexus-1.0.0-setup.exe`
  - `dist/SHA256SUMS.txt`

**Step 1: Create GitHub Release via API**

Create the release object with title `Nexus v1.0.0: Genesis Release ⚡` and rich markdown body containing the quick install table and SHA256 checksums.
Run: `curl -X POST -H "Authorization: token $GITHUB_TOKEN" https://api.github.com/repos/a1sadeq/nexus/releases -d '{...}'`
Expected: HTTP 201 with release `id` and `upload_url`.

**Step 2: Upload Release Assets**

Upload each asset binary with content-type `application/octet-stream` or `text/plain` to `https://uploads.github.com/repos/a1sadeq/nexus/releases/{release_id}/assets?name={filename}`.
Expected: Each asset returns HTTP 201 with state `uploaded`.

**Step 3: Verify Release Online**

Run: `curl -s https://api.github.com/repos/a1sadeq/nexus/releases/tags/v1.0.0 | grep -E '"name"|"browser_download_url"'`
Expected: All 5 uploaded assets listed with public download URLs.
